```

```

Pre-anticipated conflict zones:
- `app/javascript/v3/views/login/Index.vue` — Click2Run/Logto buttons + `isDefaultAuthDisabled` interleave with upstream login refresh.
- `app/services/whatsapp/providers/*` — Click2Run/Whatsmeow files alongside fazer-ai's Baileys/Z-API churn (e.g. `7a3544ba99 chore: remove zapi feature flag`).
- `docker-compose.coolify.yaml` — fazer-ai actively edits.
- `app/views/layouts/vueapp.html.erb` — `authDisableDefault` exposure may collide with new config keys.
- `lib/tasks/branding.rake` — branding system evolves.
- `app/controllers/devise_overrides/*.rb` — auth check_default_auth_disabled hooks.

Conflict-resolution heuristic:
- For Click2Run-owned files, **prefer ours** unless fazer-ai changed shared structure.
- For login/UI, **manual interleave** — preserve Click2Run UI gates.
- For Docker/CI, **prefer theirs** (fazer-ai), then re-apply our specific fixes if regressed.
- For ENV-config / DB-config files, **prefer ours** (we have specific patches like `78595b1947`, `0c0484ffb8`); re-evaluate after merge if upstream now provides equivalent.
